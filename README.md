Conductor Core
==============

This module offers common core functionality for [Conductor](https://github.com/conductorphp).

* [Documentation](docs/index.md)
* [Contributing](#contributing)
* [Report issues](https://github.com/conductorphp/conductor-core/issues)

## Requirements

* PHP 8.4.1 – 8.5
* Composer 2
* Access to the private RMG composer registry (`https://composer.rmgmedia.com/lib/`) for
  `rmg/lib-crypt-sodium`, which core encrypts configuration values with (see the docs)
